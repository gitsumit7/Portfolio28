04 / Research

Research & Exploration

Technical deep dives from what I've built, and the areas I'm studying next.

Designing a Secure Issue-Resolution Backend

Case study · ResolveHub
Backend Architecture
  • Question: How should a small team structure an Express backend so that auth, business logic and data access stay separate?
  • Approach: Split the API into controllers and authentication middleware, with PostgreSQL schema-init and user-setup scripts so any environment can be rebuilt the same way.
  • Findings: Environment-based configuration kept credentials out of code, and middleware-level auth meant protected routes needed no repeated checks.
Node.jsExpressPostgreSQLAuth Middleware

Data Modelling for Appointment Scheduling

Case study · MediCare Connect
Data Modelling
  • Question: How do you model patients, doctors and appointments in a document database without losing the relationships between them?
  • Approach: Designed Mongoose schemas for patient profiles, doctor availability and appointment records, with each appointment referencing its patient and doctor.
  • Findings: Reference-based links kept documents small and made "my appointments" and "doctor schedule" queries straightforward.
MongoDBMongooseREST APIs
